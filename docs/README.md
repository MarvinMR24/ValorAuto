# Docs

Documentación de equipo, arquitectura y proceso de ValorAuto. Para la vista general del proyecto (qué hace, pipeline, resultados), ver el [README de la raíz](../README.md).

## Contenido

- [`priorizacion_casos.md`](priorizacion_casos.md) — matriz de priorización de casos y justificación del caso elegido.
- [`contexto/`](contexto/) — Product Goal, calendario de sprints y backlog completo (historias de usuario).
- [`crisp-mlq.md`](crisp-mlq.md) — mapeo de las fases de CRISP-ML(Q) a la estructura del repo.
- [`architecture/`](architecture/) — diagramas C4 (contexto y contenedores) y de secuencia del sistema.
- [`adr/`](adr/) — Architecture Decision Records: una decisión de stack/diseño por archivo, con contexto y alternativas descartadas.
- [`evidence/`](evidence/) — evidencia ejecutada del proyecto (línea base del modelo con métricas reales, laboratorio de OpenSpec).
- [`risk-register.md`](risk-register.md) — riesgos técnicos, de datos, de IA y operacionales, priorizados.
- [`team_charter.md`](team_charter.md) — equipo, canales de comunicación, reglas de PR e integridad académica.
- [`clickup_estructura.md`](clickup_estructura.md) — estructura de ClickUp (listas, campos obligatorios, ejemplos de tarea) usada para gestionar el trabajo.
- [`uso-ia.md`](uso-ia.md) — declaración de uso de IA generativa en el proyecto.
